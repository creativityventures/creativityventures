# 45. Logs et auditabilité

Ce chapitre situe un log complet n’est pas toujours un log exploitable dans le parcours de recherche de creativityventures. Il part du point d’entrée docs/REFERENCES.md, lu comme source de comportement et non comme preuve de production.

## Question

L’objectif est de choisir événements utiles sans exposer de secrets. La lecture doit identifier les entrées, la décision produite, les données externes utilisées et l’état qui persiste.

## Lecture du mécanisme

Le fichier cité fournit le contexte concret : noms, types, ordre des contrôles et erreurs observables. Les autres conclusions doivent rester rattachées à une référence précise dans le dépôt.

## Limite

un log complet n’est pas toujours un log exploitable. Ce texte ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
