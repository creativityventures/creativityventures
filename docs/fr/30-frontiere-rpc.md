# 30. Frontière de confiance RPC

Ce chapitre situe la disponibilité d’un RPC n’est pas une preuve d’exactitude dans le parcours de recherche de creativityventures. Il part du point d’entrée docs/ARCHITECTURE.md, lu comme source de comportement et non comme preuve de production.

## Question

L’objectif est de définir ce que le client accepte d’un nœud distant. La lecture doit identifier les entrées, la décision produite, les données externes utilisées et l’état qui persiste.

## Lecture du mécanisme

Le fichier cité fournit le contexte concret : noms, types, ordre des contrôles et erreurs observables. Les autres conclusions doivent rester rattachées à une référence précise dans le dépôt.

## Limite

la disponibilité d’un RPC n’est pas une preuve d’exactitude. Ce texte ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
