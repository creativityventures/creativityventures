# Security policy

## Scope

This repository contains research and documentation about onchain systems. It is not an audit, a security guarantee or a statement that any referenced project is production-ready.

## Reporting a potential issue

If you find a security-sensitive mistake in this repository, open a private report through the GitHub security contact options when available. Include the affected file, a concise description, the impact you believe is possible and enough evidence to reproduce the observation without exposing secrets.

For issues in an upstream project, report them to that project’s official security channel and reference the upstream repository rather than treating this repository as the owner of the vulnerability.

## Research boundaries

Documentation should distinguish observed implementation details, assumptions, threat models and unresolved questions. Do not submit credentials, private keys, personal data or undisclosed exploit material in public issues or pull requests.

## Responsible handling

Security claims are reviewed for source accuracy and scope. A correction may be published when it improves safety or prevents readers from relying on an inaccurate statement.
