# Contributing

## Scope

This repository collects source-grounded research on verifiable, confidential and scalable onchain systems. Contributions should improve clarity, traceability or practical usefulness.

## Documentation standards

- Cite the relevant source files, specifications or upstream documentation.
- Separate facts observed in code from interpretation and open questions.
- State trust boundaries, assumptions and known limitations explicitly.
- Keep each change focused so that the commit history remains easy to review.

## Review checklist

Before opening a change, confirm that the text is technically precise, links are useful, and no claim implies an audit, production readiness or test result that was not actually performed.

## Contributions

Small documentation improvements are welcome. For security-sensitive topics, explain the affected component, the assumed attacker capability and the evidence supporting the observation.
